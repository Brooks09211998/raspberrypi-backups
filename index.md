# Raspberry Pi Backups

Raspberry Pi Backups is a personal, non-commercial backup utility used to securely store encrypted Raspberry Pi system and service backups in Google Drive.

## How It Works

The application uses rclone and Google OAuth to access the owner's Google Drive account.

Backup archives are encrypted locally before being uploaded to Google Drive. The application can list, upload, download, and manage backup files as needed for backup and restoration.

## Data Usage

- Google Drive access is used solely for personal backup and restoration operations.
- Backup archives are encrypted before upload.
- Google account credentials are not published or shared.
- The application does not sell or distribute user data.

## Access

This application is intended for personal use by its owner and is not offered as a public service.
